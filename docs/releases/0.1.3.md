# ICOR for Life - Terminal 0.1.3

A small fix release from the community bug reports. One real Windows
keyboard bug, and two places where the terminal did not say what had
happened to your shell. Nothing about how the terminal runs has changed.

## Fixed

- **Windows: clicking an empty terminal pane no longer swallows `Ctrl+P`
  and `Ctrl+W`.** On Windows the pane builds its terminal and takes the
  keyboard before any shell exists, so the two shortcuts were claimed for
  a shell that was never started and nothing gave them back. Keyboard
  capture now applies only while a live shell can actually receive the
  keys. The same change hands the keyboard back in any pane whose shell
  has exited, on every platform: that pane is a transcript, and its keys
  belong to Obsidian.
  Reported by Ian Slattery.

## Changed

- **A restored pane now says what ended the shell.** The first line used
  to describe only the symptom. It now names the cause, Obsidian
  restarted, for example after sleep, and the consequence in the same
  sentence: scrollback is not kept, the shell starts fresh in the same
  folder.
  Reported by Omar Nur.
- **The README states the process model in plain words.** The shell is a
  child of Obsidian's window, so reloading, updating or quitting Obsidian
  ends it, the way closing a terminal window ends the shell inside it.
  Closing the lid does not, on its own; what you usually see after a sleep
  is Obsidian reloading on wake. A job that has to survive a reload
  belongs in `tmux` or `screen` started inside the pane.

## Not in this release

- A shell that survives an Obsidian reload is a detached helper, a 0.2
  decision, not a patch.
- One cosmetic item is known and deliberately left: the pane menu title on
  a pane whose shell has already exited.

## Security posture

Unchanged. No new process family, no new permission, no change to how the
helper is started: it still runs in Python's isolated mode (`-I`), pinned
by `test/helper-isolated.test.mjs`, and every condition of the 0.1.0
security review stands.

## Install

Copy `main.js`, `manifest.json` and `styles.css` from this release into
`.obsidian/plugins/icor-for-life-terminal/` and enable the plugin in
Settings, Community plugins. Requirements and the Windows scope are
unchanged from 0.1.0.

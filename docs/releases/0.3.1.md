# ICOR for Life - Terminal 0.3.1

The terminal opens from the ribbon on the left only. The button in the file
explorer's row of icons, under the logo, is gone (Tom, 2026-11-23: every
ICOR for Life plugin's launcher moves to Obsidian's own ribbon).

## Changed

- **One entry point, in the ribbon.** The terminal icon in the ribbon opens
  the same menu the row button did: New terminal, New terminal at the active
  file, New terminal in split, your other profiles, Run Claude Code here and
  Resume a Claude session by ID. Like any ribbon icon, you can move or hide
  it in Settings, Appearance, Ribbon menu. Each fixed entry is also a command.

## Security posture

Nothing changes in what the plugin runs or reaches. No new process family, no
new permission, no change to how the helper is started.

## Install

Copy `main.js`, `manifest.json` and `styles.css` from this release into
`.obsidian/plugins/icor-for-life-terminal/` and enable the plugin in
Settings, Community plugins. Needs Obsidian 1.7.2 or newer.

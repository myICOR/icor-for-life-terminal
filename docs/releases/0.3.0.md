# ICOR for Life - Terminal 0.3.0

Vault file paths printed in the terminal are now clickable. Click opens
the file in a new tab; Cmd/Ctrl-click follows Obsidian's usual modifier
behaviour.

## Added

- **A vault file path printed in the terminal opens on click.** A path
  that the vault actually holds, in a format Obsidian opens itself
  (notes, canvases, images, audio, video, PDF), becomes a link. Paths
  with spaces and accented names work, as does an optional
  `<this vault's name>: ` prefix, and an absolute path inside the vault
  folder. A path meant for another vault, a missing file, a traversal
  (`..`), a backslash, or a type Obsidian would hand to the system
  default app (such as `.sh` or `.command`) is not linked. http(s)
  links are unchanged. Thanks to Jan (@drjanklaas) for the feature
  (#8, closes #7).

## Also since 0.2.0

- Pull-request CI, a DCO check, and a contributing note on keeping your
  GitHub email address private.

## Security posture

A link is made only when the path resolves to a file in this vault, and
only for formats Obsidian opens itself. The provider never opens a URL
scheme and never runs a file. No new process family, no new permission,
no change to how the helper is started.

## Install

Copy `main.js`, `manifest.json` and `styles.css` from this release into
`.obsidian/plugins/icor-for-life-terminal/` and enable the plugin in
Settings, Community plugins. Needs Obsidian 1.7.2 or newer.

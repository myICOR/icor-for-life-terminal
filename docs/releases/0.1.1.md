# ICOR for Life - Terminal 0.1.1

A maintenance release. It answers the findings of the Obsidian directory's
automated review of 0.1.0 and changes nothing in how the terminal behaves.

## Fixed, one per review finding

- **Manifest (error): the description named the app.** Rewritten without
  the word, same meaning, in `manifest.json`, `package.json` and the
  README's first paragraph.
- **Source code (recommendation): `setWarning` is deprecated.** The
  "Remove profile" button now calls `setDestructive` on Obsidian 1.13 and
  newer. Below 1.13 (the floor is 1.7.2) it sets the class the old call
  set, without calling the deprecated method.
- **CSS lint (warning): multi-value `text-decoration` shorthands in
  xterm's stylesheet were reported as only partially supported at the
  declared floor.** The build now splits every such shorthand into
  `text-decoration-line` and `text-decoration-style` when it assembles
  `styles.css`; the single-keyword ones (`underline`, `overline`,
  `line-through`) were not flagged and are kept. A headless-Chrome test
  proves each xterm decoration class still resolves to the same computed
  underline style, overline and strikethrough, and the live pane was
  checked with `printf '\e[4munderline\e[0m \e[9mstrike\e[0m\n'`.
- **Releases (recommendation): no artifact attestations.** This release
  is published by `.github/workflows/release.yml`: on a bare version tag
  it runs the full gate on the tagged commit, attests `main.js`,
  `manifest.json` and `styles.css` with GitHub artifact attestations and
  uploads exactly those three assets. Verify with
  `gh attestation verify main.js --repo myICOR/icor-for-life-terminal`.

## Acknowledged, no change

- **Licence (warning): "not a recognized license".** The plugin ships
  under the ICOR for Life Source-Available License (Code), Version 1.0,
  the licence of the whole ICOR for Life suite (ICOR for Life - AI Chat
  carries the same warning). It is source-available, not open source, and
  it stays that way on purpose; full terms in `LICENSE`.
- **Behaviour (warnings): file system access outside the vault, process
  spawning, clipboard use.** All three are what a terminal is. Each is
  described plainly in the README's disclosure section and in
  `SECURITY.md`, with the file to read behind every claim.

## Security posture

No new spawn path. The helper still runs in Python's isolated mode (`-I`),
pinned by `test/helper-isolated.test.mjs`, and every other condition of the
0.1.0 security review stands unchanged.

## Install

Copy `main.js`, `manifest.json` and `styles.css` from this release into
`.obsidian/plugins/icor-for-life-terminal/` and enable the plugin in
Settings, Community plugins. Requirements and the Windows scope are
unchanged from 0.1.0.

# ICOR for Life - Terminal 0.1.2

A maintenance release. It answers the remaining findings of the Obsidian
directory's automated review of 0.1.1 and changes nothing in how the
terminal behaves, with one visible exception in the DOM renderer, named
below.

## Fixed, one per review finding

- **CSS lint (warning): `text-decoration` "only partially supported" at
  the floor**, on the `text-decoration-line` plus `text-decoration-style`
  longhands that 0.1.1 introduced for xterm's styled underlines. The
  review's baseline flags a styled or two-line decoration in any spelling,
  so the stylesheet now carries only the plain single-keyword forms
  (`underline`, `overline`, `line-through`): at assembly, every styled
  underline class (`.xterm-underline-2` to `-5`) and every overline plus
  underline pair is mapped to a plain `underline`, and no longhand
  remains. The cost is confined to the DOM renderer, the fallback behind
  WebGL: it draws double, wavy, dotted and dashed underlines as a plain
  underline. The WebGL renderer, the default, draws decorations on its
  canvas and never reads these rules; checked live in a pane with
  `printf '\e[4:3mwavy\e[0m\n'`. The README lists the limit under
  "Does not match yet"; the headless-Chrome test pins the new computed
  decorations and the hygiene test refuses any longhand.
- **Behaviour (warning): "Direct Filesystem Access: Uses the Node.js fs
  module."** The plugin's only `fs` use was `existsSync` plus `statSync`
  in the executable check for `claude` and the Python interpreter. The
  import is gone: a candidate is now probed by running it,
  `child_process.spawnSync(candidate, ['--version'])` with no shell,
  `stdio: 'ignore'` and a 1.5 s timeout, a spawn error meaning "not
  found", and the verdict remembered per path until settings are saved.
  No spawn path's arguments change beyond these probes; the helper still
  runs with `-I` and every condition of the security review stands.
  `SECURITY.md` lists the probes in the spawn inventory and the hygiene
  test refuses any `fs` import in `src/`.

## Acknowledged, no change

- **Behaviour (recommendation): clipboard use.** Inherent: `Cmd+C`,
  `Cmd+V` and the opt-in copy on select. The README and `SECURITY.md`
  each say so in one sentence, unchanged from 0.1.1.
- **Licence (warning): "not a recognized license".** The licence stays
  the ICOR for Life Source-Available License (Code), Version 1.0. The
  README's "Licence" section now says in plain words what it allows
  (install, read, modify for yourself) and what it does not
  (redistribute, resell), and a new "What the directory review shows"
  section reads the whole report against the code.

## Security posture

No new process family: the two probes run `claude --version` and
`python3 --version` (or the interpreter you configured) and nothing else.
The helper still runs in Python's isolated mode (`-I`), pinned by
`test/helper-isolated.test.mjs`, and every other condition of the 0.1.0
security review stands unchanged.

## Install

Copy `main.js`, `manifest.json` and `styles.css` from this release into
`.obsidian/plugins/icor-for-life-terminal/` and enable the plugin in
Settings, Community plugins. Requirements and the Windows scope are
unchanged from 0.1.0.
